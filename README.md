# Midas Transaction Processing System

Built as part of JPMorganChase Software Engineering 
Job Simulation on Forage (April 2026)

## About The Project
A Spring Boot microservice that processes high-volume 
financial transactions using Apache Kafka, persists 
data with Spring Data JPA and SQL, and communicates 
with an external Incentive REST API.

## Tech Stack
- Java
- Spring Boot
- Apache Kafka
- Spring Data JPA
- H2 SQL Database
- REST API / RestTemplate
- Maven

## What I Built
- Kafka consumer for transaction message processing
- Transaction validation and database persistence
- External REST Incentive API integration
- REST endpoint for user balance queries
- Maven test suites for system verification
